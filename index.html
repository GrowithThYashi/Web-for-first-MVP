01 / THE BEGINNING

I was not trying to build the perfect game.

I had a simple idea: control a box and avoid falling objects.

My goal was to turn that idea into working software within a few hours and understand the process of building a real project.

01

The original goal

Build a playable MVP quickly, test it, publish it and learn from the process.

02

The real challenge

Turning ideas into working code, understanding bugs and improving the project without breaking the previous version.

02 / DEVELOPMENT TIMELINE

Six versions. One learning journey.

VERSION 01

COMPLETED · FIRST MVP

From idea to playable game

The first version focused on making the basic idea playable: moving a box and avoiding falling objects.

What changed

Created the first playable prototype with basic movement, falling objects and a score system.

What I learned

Basic HTML, CSS, JavaScript, game logic and browser testing.

My biggest challenge

Turning the idea into code that actually worked.

04 / HOW I USED AI

AI helped write code. I still had to build the project.

01

Describe the idea

I explained the gameplay, design and features I wanted.

02

Test the result

I opened the game, tested the controls and checked whether the result matched my idea.

03

Find the problems

When the game crashed or behaved incorrectly, I identified what changed and described the problem to AI.

04

Iterate carefully

I reverted broken changes, tried new prompts and continued improving the project.
